2. Microsoft Edge WebView2 Runtime

Plain Viewer shows PDF, Word, Excel and PowerPoint files with the Microsoft Edge WebView2 Runtime. This installer contains Microsoft's offline installer for the runtime. If the runtime is missing on this PC and you keep the option "Install the Microsoft Edge WebView2 Runtime" selected, it installs the runtime.

If you install it, you agree to Microsoft's terms. Microsoft shows them on its WebView2 page when you choose to download the runtime:
https://developer.microsoft.com/microsoft-edge/webview2/
Microsoft's privacy statement: https://aka.ms/privacy

Once installed, the WebView2 Runtime is a shared part of Windows. It updates itself through Microsoft's update service and stays installed when you uninstall Plain Viewer. Plain Viewer turns off the runtime's SmartScreen checks and never loads web content from the internet.
