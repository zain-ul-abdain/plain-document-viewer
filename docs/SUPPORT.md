No format is release-certified. The Open dialog labels implemented formats as a development preview.

## Safety scope

Markdown image/file references are never followed by implemented code. Links require an allowed scheme and confirmation. Document HTML/XAML is never instantiated. The worker uses a Windows Job Object with a 256 MB memory cap, one-process limit and kill-on-close. Parent enforces 20 seconds for opening and 32 MB for serialized output.

Privilege isolation (Zain's gate 1 decision, DECISIONS.md): the worker drops to low integrity before it reads a document and refuses to continue if it cannot; LibreOffice is started at low integrity in a Job Object limited to its launcher plus one process. At low integrity Windows stops them writing the user's files and registry and opening other programs to change them (tested: `test.ps1` low-integrity test; all LibreOffice processes observed at low integrity). They can still read files the user can read. PDF pages (PDF.js) and the spreadsheet grid run inside WebView2, in Chromium's renderer sandbox.

Network: the installer's optional "firewall" task adds Windows Firewall rules, after one administrator prompt, that block the worker, LibreOffice and LibreOffice's Python in both directions; About shows whether they are present. Without those rules there is no OS-level network block for the worker or LibreOffice, only the layered measures (sanitised copies, hardened LibreOffice settings, dead proxy). Even with them, network access that Windows performs for a program through system services (DNS lookups, network-share access by the SMB client) is not covered. This is weaker than an AppContainer, which LibreOffice cannot run in. Not yet done: source-handle race hardening and a full process-failure suite.

Originals use shared read/write/delete access. Current text paths keep data in memory and make no temporary disk copies. Final modification checks may reject a source moved during opening. Signature/control-character screening rejects obvious binary mismatches; extension selects presentation among text/CSV/Markdown, which have no unique magic bytes.
