# Fixture provenance

All checked-in fixtures were authored for this project by Codex as plain UTF-8 text. Producing application: Codex file-writing tool, not a rendering engine. They contain no personal/company data or third-party prose. Project permission: these original fixtures may be used and redistributed with the project.

| Files | Purpose | Expected result |
|---|---|---|
| simple.txt, complex.txt | Basic and multilingual text | Exact Unicode text displayed |
| simple.csv | CSV values | Three columns, two rows, preserve 001 |
| complex.csv | Semicolon delimiter, quoting, multiline field | Three columns, three logical rows |
| simple.md | Heading, emphasis, code, link, list | Native Markdown blocks; link requires confirmation |
| complex.markdown | Tables, tasks, RTL/CJK, HTML, unsafe references | Literal HTML, inert image placeholders, no reference reads by application code |

Core tests generate temporary malformed CSV, ZIP expansion/traversal, XML entity, empty and wrong-extension fixtures. These are original synthetic fixtures generated by PlainViewer.Tests, .NET ZipArchive and text APIs. They test parser boundaries, not independent Office fidelity.

Large-file corpus, Office-produced fixtures, PDF/Office RTL comparisons and observed network instrumentation are still pending. No claim of release-format acceptance is made.
