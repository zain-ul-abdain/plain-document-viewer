# Plain Viewer

A read-only document viewer for Windows 11: open a file, read it, close it. It works fully offline, needs no Microsoft Office, and never changes, moves or writes beside the files it opens. **Status: public beta** (not yet code-signed).

Download: [Releases](https://github.com/zain-ul-abdain/plain-document-viewer/releases). Guide for testers: [docs/BETA.md](docs/BETA.md). Report problems: [Issues](https://github.com/zain-ul-abdain/plain-document-viewer/issues/new/choose).

## What it does

- Opens PDF, Word, Excel and PowerPoint files (including templates, shows and macro-enabled files, with macros removed and never run), pictures (JPEG, PNG, GIF, BMP, ICO, WebP, AVIF, SVG), CSV, text, Markdown and plain-text data files (JSON, XML, log, INI, YAML). One document per window; Open, drag and drop, "Open with" and command-line loading.
- Search, copy, zoom, fit, page thumbnails, rotate for pictures, Excel formatting, sheet tabs and frozen panes, light/dark theme, keyboard shortcuts.
- Documents are read by a separate low-integrity worker with time and memory limits; PDF pages, spreadsheets and pictures are drawn in a locked-down WebView2 that may load nothing but the document; Word and PowerPoint are converted by a bundled, hardened LibreOffice. Nothing is uploaded and no network is used.

Format by format status, limits and test evidence: [docs/SUPPORT.md](docs/SUPPORT.md) and [docs/TEST-RESULTS.md](docs/TEST-RESULTS.md).

## Build, test and package

Windows with the .NET 10 SDK (installed normally or under `.tools/dotnet`). From the repository root in PowerShell:

```powershell
.\scripts\build.ps1
.\scripts\test.ps1               # core tests, including every fixture in tests/corpus/manifest.json
.\scripts\test-markdown.ps1
.\scripts\test-office-safety.ps1
.\scripts\smoke-test.ps1         # opens files of every format in real windows
.\scripts\security-smoke.ps1     # hostile and broken files, with a listener that records any network request
.\scripts\run.ps1 -File "$PWD\tests\corpus\complex.markdown"
```

Word and PowerPoint need LibreOffice for development: `.\scripts\fetch-libreoffice.ps1`. The offline installer, its one-time setup and the release steps are in [docs/RELEASING.md](docs/RELEASING.md). Test fixtures are generated by `tests/corpus/generate` (see [tests/corpus/SOURCES.md](tests/corpus/SOURCES.md)).
